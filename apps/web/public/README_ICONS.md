# Ícones do App

Para o Web App Manifest funcionar completamente, você precisa adicionar os seguintes ícones na pasta `public`:

- `icon-192.png` - Ícone 192x192 pixels
- `icon-512.png` - Ícone 512x512 pixels

Estes ícones são usados quando o usuário adiciona o app à tela inicial do dispositivo móvel.

**Nota:** O app funcionará sem os ícones, mas eles melhoram a experiência do usuário em dispositivos móveis.
