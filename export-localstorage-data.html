📦 Exportar Dados do LocalStorage

Como usar:

  1. Abra esta página no mesmo navegador onde você usa a aplicação
  2. Clique no botão abaixo para exportar os dados
  3. O arquivo data-export.json será baixado automaticamente
  4. Salve o arquivo na raiz do projeto (mesmo diretório do package.json)
  5. Execute npm run migrate para importar os dados no SQLite
